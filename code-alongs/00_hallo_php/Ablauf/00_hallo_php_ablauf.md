# Ablauf `00_hallo_php`

> **Ziel:** Der technische Weg vom lokalen Kursordner über den Server bis in
> den Browser funktioniert. PHP-Syntax ist an Tag 1 noch kein Lerninhalt.

## Vorbereitung

- Keine

## Schritte

1. Den Ordner `00_hallo_php` lokal öffnen.
2. Die Datei `index.php` so verändern, dass "Hallo PHP" ausgegeben wird.
3. Die Datei auf den Server hochladen.
4. Die entsprechende URL im Browser aufrufen.
5. Prüfen, ob `Hallo PHP` erscheint.
6. Falls nichts erscheint, gemeinsam URL, Pfad, Dateiname und Upload-Ziel
   prüfen.

## Abnahme

Jede Person zeigt `Hallo PHP` unter ihrer eigenen URL. Der PHP-Code wird an
diesem Tag nicht erklärt; er ist nur das Prüfwerkzeug.
