# Stift und Papier

Diese Übungen planen oder simulieren Code, bevor er am Computer umgesetzt
wird. Die Gruppen arbeiten zuerst ohne Editor und ohne KI-Tool.

## Block A – PHP Basics

- [Messwertmaschine](01_messwertmaschine/): Eine kleine Liste von
  Aare-Messungen von Hand durch Funktion, Bedingung und Schleife führen.

## Block C – Transform

- [Transform-Entscheidungen](02_transform_entscheidungen/): Eine Datenfrage in
  Auswahl, Kategorien, Untersuchungseinheit, Datenvertrag und Audit übersetzen.
