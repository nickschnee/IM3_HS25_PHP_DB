# Theorie A – PHP Basics

Die Präsentation verbindet die PHP-Grundlagen mit einem kleinen
Aare-Messwert. Sie ist auf zwei Inputs verteilt:

- **Tag 2:** Folien 1–12 – Server, Variablen, Datentypen, Debugging,
  Funktionen und Bedingungen.
- **Tag 3:** Folien 13–19 – Arrays, assoziative Arrays, Schleifen und die
  Brücke zu JSON.

[`index.html`](index.html) direkt im Browser öffnen. Mit den Pfeiltasten,
`Page Up`, `Page Down`, `Home` und `End` kann navigiert werden. Die Taste `F`
schaltet den Vollbildmodus um. Für Handouts kann die Seite gedruckt oder als
PDF gesichert werden.

Die Folien sind kein Selbstlern-Skript. Kurze Syntaxdetails stehen in den
Cheatsheets; nach spätestens 20 bis 40 Minuten folgt im Unterricht ein
Code-Along oder eine Übung.
