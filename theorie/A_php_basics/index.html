Minimaler Start

PHP beginnt mit einem klaren Signal.

<?php

// PHP verarbeitet diese Zeile.
echo "Aare: 19.4 °C";

1<?php öffnet den PHP-Bereich.

2echo schreibt etwas in die Antwort.

3Das Semikolon beendet die Anweisung.

Eine fehlende Klammer oder ein fehlendes Semikolon kann das ganze Skript stoppen.

Variablen

Eine Variable gibt einem Wert einen Namen.

$location = "Bern";
$temperatureC = 19.4;
$measuredAt = "10:00";

echo $location;

Funktionen

Eine Funktion ist eine benannte, wiederverwendbare Regel.

function formatMeasurement($location, $temperatureC) {
  return "$location: $temperatureC °C";
}

$message = formatMeasurement("Bern", 19.4);
echo $message;
Parameter kommen hinein Regel verarbeitet sie return gibt einen Wert zurück

Bedingungen

Eine Bedingung lässt Daten unterschiedliche Wege nehmen.

if ($temperatureC >= 20) {
  $label = "warm";
} else {
  $label = "frisch";
}
19.4 ≥ 20?
ja→ warm
nein→ frisch

Die Reihenfolge der Fälle ist Teil unserer fachlichen Regel.

PHP Basics II

Ein Messwert reicht selten für eine Geschichte.

Heute wird aus einzelnen Werten eine strukturierte Liste.

Arrays

Ein Array speichert mehrere Werte in einer Variable.

$temperatures = [
  18.9,
  19.4,
  20.1
];

echo $temperatures[0];
018.9
119.4
220.1

Der erste Index ist 0, nicht 1.

Assoziative Arrays

Schlüssel geben den Feldern Bedeutung.

$measurement = [
  "location" => "Bern",
  "temperature_c" => 19.4,
  "measured_at" => "10:00"
];

echo $measurement["location"];

Diese Feldnamen begleiten uns später bis in Datenbank und JSON.

Liste von Datensätzen

Eine Datenliste ist ein Array aus assoziativen Arrays.

$measurements = [
  ["time" => "10:00", "temperature_c" => 19.4],
  ["time" => "11:00", "temperature_c" => 19.8],
  ["time" => "12:00", "temperature_c" => 20.1]
];
äusseres Array = ganze Liste inneres Array = ein Datensatz Schlüssel = ein Feld
Schleifen

foreach wiederholt denselben Schritt für jeden Datensatz.

foreach ($measurements as $measurement) {
  echo $measurement["time"];
  echo $measurement["temperature_c"];
}
