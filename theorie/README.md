geordnet. Sie sind für den gemeinsamen Unterricht gedacht und ersetzen die
kurzen Cheatsheets nicht.

| Block | Thema | Status |
| --- | --- | --- |
| [A](A_php_basics/) | PHP Basics | Erste unterrichtbare Fassung |
| B | PHP, JSON und APIs | Offen |
| C | Datenbanken und PDO | Offen |
| D | ETL+U-Pipeline | Offen |
| E | Chart.js | Offen |
| F | Datenjournalismus | Offen |

Die Präsentationen laufen direkt im Browser. Hinweise zur Auswahl der Folien
stehen jeweils im Ordner des Theorieblocks.
