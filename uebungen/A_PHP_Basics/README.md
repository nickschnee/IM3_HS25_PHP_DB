# Übungen A – PHP Basics

Die Übungen 01–05 folgen dem Lernpfad aus Theorieblock A. Sie sind bewusst
kurz. Pro Übung steht ein neues Konzept im Zentrum. Die Capstone-Übung 06
kombiniert am Schluss alles zu einer kleinen Text-API.

| Übung | Konzept | Richtwert |
| --- | --- | ---: |
| [01 Messwert](01_messwert/) | Variablen und `echo` | 20' |
| [02 Badewetter](02_badewetter/) | Funktion, Parameter und `return` | 25' |
| [03 Warnstufe](03_warnstufe/) | `if`, `elseif`, `else` | 25' |
| [04 Messstation](04_messstation/) | Assoziatives Array | 25' |
| [05 Aare-Woche](05_aare_woche/) | Liste und `foreach` | 35' |
| [06 Städtevergleich](06_staedtevergleich/) | Alles kombiniert (offen, Capstone) | 45' |

Der Startcode liegt jeweils in `index.php`. Erst nach einem eigenen Versuch
mit der Datei in `solution/` vergleichen.
