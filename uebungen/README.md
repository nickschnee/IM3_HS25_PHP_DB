# Digitale Übungen

Die Übungen sind selbständig lösbar. Jeder Ordner enthält:

- eine kurze Aufgabenstellung in `README.md`;
- ausführbaren Startcode;
- eine vollständige Lösung in `solution/`;
- eine klar markierte freiwillige Zusatzaufgabe.
